# SSGA: Sovereign Static Generated Architecture

The Sovereign Static Generated Architecture (SSGA) is a universal, framework- and platform-agnostic web governance model for building deterministic, static, human-governed web systems and creative content.

SSGA is declared public commons, open source, and irrevocable prior art, free for all developers and creators. See [LICENSE](LICENSE).

**Originator:** Galen W. Tenney, Founding SSGA Architect, Founder of Auralicode® LLC
**Website:** https://auralicode.com/ssga-overview
